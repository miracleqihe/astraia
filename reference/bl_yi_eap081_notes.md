# 云南彝语口述录音馆藏：EAP081/25

[大英图书馆馆藏组](https://searcharchives.bl.uk/catalog/032-001617335)登记了中山大学与彝族文化研究机构合作的口述资料。目录将录音按六位毕摩讲述者分成六个子组，父级登记 81 个音频文件、约 22 小时。本批建立一张馆藏组卡与六张子组卡；文件数和子组数均不是故事篇数，也不能在未听录音前推定每件的体裁或内容。

馆藏组说明称项目在 2004—2009 年进行，六个子组内容说明分别记载 2004、2006 或 2007 年的录音；目录统一日期字段却为 1560—1940。两类字段的含义与来源尚待馆方复核，不将任何一处自动转为叙事年代。六组所列时长相加为 18 小时 55 分钟，父级为约 22 小时；这是一处计数口径待核差异，不自行修改原始字段。

[EAP081/25/4](https://searcharchives.bl.uk/catalog/040-001617339) 的题名使用 `Pu Rongxiang`，内容说明使用 `Pu Rongziang`；两处原拼写均保留，不自动判断身份或更正。[EAP081/25/6](https://searcharchives.bl.uk/catalog/040-001617341)说明中的讲述者来源地和所述方言是不同字段，不能相互替代，更不能直接作为录音坐标。馆方标示的语言名称也按原字段保留，不由此断定每个文件中的实际用语。

馆方目录页面声明文字按 CC BY 4.0 许可；录音子组注明仅供研究使用，录音、转写和相关社区要求须分别核查。本项目保存馆方目录网页及哈希，未下载录音或转写。数字内容入口本次返回人机验证页面，未绕过验证；这不代表馆方音频不存在或其他用户一定无法访问。
