选购包装食品时，把食品名称、配料、日期、储存条件和食用方法一起看。先按标签引导查找日期，例如“见瓶肩”；要求冷藏的食品在购买和回家途中也要保持冷藏。包装破损、冷链中断或已经开封时，原定保存期限可能不再适用。

**开封后的期限。** 按包装上的开封后冷藏方式和使用期限处理，并在容器上记下开封日期；缺少说明时可向生产者询问。比如酱料标注“开封后冷藏”，放在高温厨房过久，即使还没到标示日期也不能凭日期认定安全；闻起来正常同样不能证明安全。

日期术语要按销售地区理解。在美国，“Best if Used By/Before”通常表示建议的最佳品质日期；婴儿配方奶的日期有特别要求，过了标示的使用日期不要使用。中国食品的生产日期、保质期等应依中国适用规则及标签理解，不能直接套用美国日期术语；不同生产日期的产品还可能处在不同规则的过渡期内。

买罐头时顺便看包装：鼓胀、渗漏、严重凹陷或玻璃瓶破裂、盖子鼓起的产品不要购买或食用；开封时异常喷出液体也应停止使用。不要为确认是否变质而试吃。包装完整只能说明未发现这些外观异常，仍须结合日期、储存和厂商说明。

#### LIF-KITCHEN-0009 — 食品标签、日期标识与储存说明 {#task-lif-kitchen-0009}

[返回本条](#entry-lif-kitchen-0009)

- **问题**：怎样分别记录食品日期和罐体异常？
- **材料**：模拟罐 A 的罐体有渗漏；模拟罐 B 外观完好，标签写 `Best if Used By 2026-01`，假设检查日期为 2026-11。
- **执行步骤**：分别记录日期标签、包装状况和保存条件；遇到渗漏、鼓胀或严重变形的罐头按当地指引处置，不尝试食用。
- **示范成果**：A 因渗漏不使用；B 已超过标示日期，需结合当地标识规则、产品说明与储存情况判断，不能只凭日期或外观确认安全。
- **完成标准**：分别列出日期与罐体状态，并解释 B 还缺少哪些判断信息。
- **来源**：[美国农业部，破损罐头](https://ask.fsis.usda.gov/article/Is-food-in-damaged-cans-dangerous)；[美国食品药品监督管理局，日期标识](https://www.fda.gov/food/consumers/how-cut-food-waste-and-maintain-food-safety)。美国日期标识的含义需结合所在地区规定。
