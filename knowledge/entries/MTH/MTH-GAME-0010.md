每个人的偏好都可以前后一致，群体两两多数比较仍可能绕回起点。假设三人的排序分别是 `A＞B＞C`、`B＞C＞A`、`C＞A＞B`。

把 A 与 B 比较，第一、第三人选 A，A 以二比一胜；B 与 C 比较，前两人选 B；C 与 A 比较，后两人选 C。于是得到 A 胜 B、B 胜 C、C 又胜 A，形成多数决循环。

这说明提案和表决顺序可能影响结果。实际投票还要看选民资格、弃权、平票和议程规则。
