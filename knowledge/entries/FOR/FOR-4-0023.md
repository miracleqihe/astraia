**疑似暴露时先处理人。** 不必先确定毒物或等待检验：按[疑似中毒的行动顺序与分类处置](#practical-poison)离开危险、求助并按接触途径处理；具体医疗措施由急救和中毒专科判断。
以下按物质列出主要识别线索与检测方向。出现症状应立即就医并告知接触史；已知或高度怀疑危险暴露时，即使暂时无症状也要迅速联系急救或中毒救治机构。检测须由实验室执行。


**气体、蒸气及部分相关物质**

1\. **一氧化碳**：头痛、头晕、恶心、意识模糊，多人同时发病、室内取暖环境是线索；只有一人不适也不能排除，皮肤“樱桃红”不可靠。怀疑中毒时立即离开危险环境，到新鲜空气处联系当地急救或急诊；不要返回危险区取物或无防护施救。有人意识不清或呼吸异常时立即呼叫当地急救。医护可检测血中碳氧血红蛋白并给予氧疗，根据病情判断是否需要高压氧；检测或等待高压氧不应耽误救治。

2\. **氰化物（氰化氢/氰化钾/氰化钠）**：氰化氢易挥发形成有毒气体，氰化钾和氰化钠常见为固体盐。怀疑危险暴露，如误食氰化物盐或吸入氰化氢，应立即离开危险环境并呼叫当地急救，告知疑似物质。旁人不要进入危险区，不要催吐；避免接触可能释放有毒气体的呕吐物，不做直接口对口人工呼吸。施救者能安全接近并安全接触患者、患者无反应且无正常呼吸时，按急救调度员指导立即开始胸外按压。暴露后可先有头晕、乏力、呼吸急促、恶心或意识混乱，大量暴露可迅速抽搐、昏迷。吸入氰化氢时症状可能在数秒至数分钟出现，其他接触途径和剂量的起效时间不同。有些病例呈鲜红或樱红肤色，也可苍白、发灰或发绀；苦杏仁味并非总出现，也不是人人能闻到。血氰化物、乳酸及解毒剂由医护结合暴露经过评估。苹果籽等种仁完整误吞与咀嚼、破碎后吞食的区别见[氰化物：可能的外观、气味和紧急处理](#entry-che-6-0042)。

3\. **硫化氢**：下水道、化粪池和井窖可能积聚；可有臭鸡蛋味，但嗅觉会疲劳，闻不到也可能有危险。高浓度可使人迅速失去意识。有人在有限空间倒下时，旁人留在外面报警、呼叫消防与急救，等待配备防护的救援人员；不要凭气味判断后下去救人。现场气体检测和医疗供氧由专业人员实施。

4\. **氯气**：漂白剂与酸混用可能释放氯气，出现眼鼻刺激、咳嗽、胸闷或呼吸困难；较重暴露后肺损伤也可能延迟加重。立即离开污染处，到安全空气中并求助，说明接触时间与产品；检测主要结合暴露史和临床检查。

```{=typst}
]
```




```{=typst}
#block(breakable: false)[
```

5\. **氨**：氨水等清洁用品可释放刺激性气体，引起眼鼻灼痛、咳嗽或呼吸困难，高浓度可损伤气道。迅速离开污染处，眼部接触后用流动清水冲洗并求医；不要将含氨清洁剂与含氯漂白剂混用。

```{=typst}
]
```

6\. **光气**：化工、焊接或加热某些含氯溶剂时可能出现。起初可有咳嗽、胸闷、眼喉刺激，也可能感觉不明显；呼吸困难可在数小时至两三天内出现或加重，严重时可咳出白色或粉红色泡沫。疑似接触应远离现场并尽快就医，说明时间和可能接触物，不能因当时能正常说话而自行结束观察。

7\. **二氧化碳**：可在发酵池、井窖等处积聚；高浓度既可降低空气中的氧，也可直接引起呼吸、意识及酸碱平衡异常，严重时昏迷。有人在有限空间倒下时，处于安全处的旁人应留在外面立即呼叫消防与急救，说明可能缺氧或有有害气体；不要进入有限空间盲目施救，等待受训且配备防护的救援人员。

8\. **氮氧化物**：可见于青贮饲料设施、焊接等环境。接触后可咳嗽、胸闷，起初较轻时仍可能在数小时至一两天后出现严重呼吸困难。迅速离开污染区域并及时就医，告知可能的接触经过。

9\. **臭氧**：某些复印和消毒设备可产生臭氧，吸入可能引起咳嗽、喉咙干痛、胸闷和呼吸困难。出现刺激症状应离开污染区域；症状持续或呼吸不适时求医。

10\. **磷化氢**：磷化铝熏蒸剂遇水可释放；暴露后可出现胃肠症状、呼吸困难、低血压及心律失常。纯气体无味，产品中可能出现的蒜味不能用于判断安全。迅速远离并呼救，现场检测由专业人员进行。

11\. **砷化氢**：冶炼或金属酸洗等场所可能产生。初期可头痛、腹痛、乏力，随后可能出现红色或深色尿、黄疸；它损伤红细胞，严重时引发肾损伤。溶血和肾损伤可延迟显现，疑似吸入应立即离开现场并就医，不等尿色改变。

12\. **苯**：常见于部分工业原料和溶剂；急性高浓度吸入可致头晕、意识改变，长期接触可能损害造血系统。疑似吸入先离开污染环境；严重暴露或出现症状立即求医，带产品名称与接触经过。

13\. **甲醇**：可见于工业酒精和被污染的酒；怀疑饮入含甲醇的工业液体或被甲醇污染的饮品，立即联系当地急诊或中毒救治机构，即使暂时没有症状也不要等待；不要催吐。潜伏期后可出现视力模糊和代谢性酸中毒。医护可根据病情使用甲吡唑或乙醇，并判断是否透析；切勿自行饮酒解毒。详见[甲醇暴露与延迟症状](#entry-for-4-0011)。

```{=typst}
]
```




```{=typst}
#block(breakable: false)[
```

14\. **乙二醇**：见于部分防冻液；怀疑饮入时立即联系当地急诊或中毒救治机构，不要因暂时无症状而等待，也不要催吐。早期可似醉酒，随后可出现代谢性酸中毒和肾损伤。急诊或中毒专科根据病情决定治疗及是否透析，不要自行饮酒解毒。详见[乙二醇误饮](#entry-che-6-0038)。

```{=typst}
]
```

15\. **异丙醇**：见于部分消毒剂；饮入后可出现呕吐、走路不稳和嗜睡，严重时影响意识与呼吸。怀疑饮入时立即联系当地中毒救治机构或急诊，不要催吐；抽搐、呼吸异常或叫不醒时立即呼叫当地急救。安全且不耽误求助时，带上原包装或拍下产品信息。医护评估时可见酮体增多而不伴明显代谢性酸中毒；严重低血压或合并摄入其他物质时也可能出现酸中毒。见[含氯漂白剂与酒精条目中的误饮提示](#entry-che-6-0041)。

**金属与类金属**


```{=typst}
#block(breakable: false)[
```

16\. **铅**：长期暴露可能影响造血、神经系统及儿童发育，也可能出现腹痛；儿童接触后不一定有明显症状。怀疑持续或反复低量接触时，应尽量停止接触可疑铅源，并与医护讨论血铅检测和后续随访。让儿童远离疑似含铅的剥落涂层和粉尘；不要自行干磨或烧除可疑涂层，以免产生可能含铅的粉尘或烟尘。咨询当地卫生、生态环境等相关部门或有相应检测能力的机构，了解可疑涂层和粉尘的检测与处置。任何人吞下疑似含铅坠子等异物，如出现呼吸困难、抽搐或无反应，应立即呼叫当地急救；即使没有这些表现，也应立即联系当地中毒救治机构或急诊，不等症状或血铅结果。螯合治疗由医护结合血铅水平与病情决定。

```{=typst}
]
```

17\. **汞**：破碎体温计中的金属汞在常温下也会挥发，加热会加快；吸入汞蒸气可损伤呼吸道和神经系统。先让儿童、宠物离开，别用吸尘器或扫帚清理，也不要倒入下水道，按当地卫生或环保部门指引处理。无机汞盐还可腐蚀胃肠并损伤肾脏；甲基汞暴露可引起感觉异常和共济失调。尿汞常用于评估元素汞及无机汞，血液或头发可用于评估甲基汞；总汞结果须结合接触史和检测方法解释。

```{=typst}
]
```




```{=typst}
#block(breakable: false)[
```

18\. **砷**：急性暴露可出现恶心、呕吐、腹痛和腹泻，严重时脱水或休克；这些表现并非砷特有。慢性暴露可有皮肤角化和色素变化。过去 48 小时吃过海鲜的人，尿总砷可能因食物中的砷升高；应告知医生饮食史，必要时区分砷的形态。怀疑急性中毒时立即就医，不为等饮食影响消退而耽误救治。

```{=typst}
]
```




```{=typst}
#block(breakable: false)[
```

19\. **铊**：急性中毒可能先有恶心、呕吐、腹痛，随后数天出现手足疼痛、烧灼感或无力；有些人在约 2—3 周后明显脱发。症状先后和出现时间随剂量变化，不要等脱发才就医。医护结合接触史安排血、尿铊检测；药用普鲁士蓝可由医生用于治疗，颜料不能代替药物。

21\. **铬（六价）**：可能出现在电镀等工作中，可刺激呼吸道或损伤皮肤。停止接触，皮肤受污染时脱掉污染衣物并以大量清水冲洗；显著暴露及时就医并提供产品信息。

22\. **钡（可溶性钡化合物及碳酸钡）**：碳酸钡虽难溶于水，仍可能在胃内溶解。误食后可出现胃肠不适、肌无力及心律异常。立即联系急救或中毒专科，不催吐；医护会评估心电图与电解质。这些物质不同于医疗检查用的硫酸钡制剂。
