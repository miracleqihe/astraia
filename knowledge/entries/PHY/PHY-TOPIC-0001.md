屏幕上的颜色来自不同通道的光；水彩、颜料和油墨的颜色则与它们吸收、散射和反射光的方式有关。两种情况不能把同一张混色表直接套用。

#### 屏幕光的加色

在理想的红、绿、蓝加色模型里，让两种光在同一区域叠加，可以得到下表。色号是 sRGB 屏幕颜色的例子，每对十六进制数分别表示红、绿、蓝三个通道。

| 叠加的光 | 理想结果 | 示例色号 |
|---|---|---|
| 红 + 绿 | 黄 | `#FFFF00` |
| 绿 + 蓝 | 青 | `#00FFFF` |
| 蓝 + 红 | 品红 | `#FF00FF` |
| 红 + 绿 + 蓝，三个通道码值都取最大 | sRGB 的参考白 | `#FFFFFF` |

![红、绿、蓝光的理想加色示意，自制图](figures/everyday/rgb-addition.svg){width=65%}

这些是模型中的结果；不同屏幕、亮度设置和环境光会改变眼睛看到的效果。屏幕上的“黄”不是先有一支黄色颜料，而是由显示设备的红、绿通道共同产生的视觉效果。

#### 颜料混合：先做小样

颜料的配方很多，下表只适合当作开始实验的方向，不能保证任意两种颜料混合后都得到同一色号。

| 尝试混合 | 常见观察 | 还要注意什么 |
|---|---|---|
| 红 + 黄 | 常呈橙色 | 两种颜料偏冷或偏暖，结果会变化 |
| 黄 + 蓝 | 常呈绿色 | 有些组合偏灰或偏褐 |
| 红 + 蓝 | 可能呈紫色，也可能偏暗 | 具体颜料决定结果，鲜艳的紫并非总能得到 |
| 红 + 白 | 常呈较浅的粉色 | 白色颜料可能改变遮盖力 |
| 黑 + 白 | 常呈灰色 | 比例和颜料本身都会影响深浅 |
| 红 + 绿 | 可能变成较灰、较褐的颜色 | 不能承诺得到固定的棕色 |

理想减色模型中，青加黄得绿，品红加黄得红，青加品红得蓝；实际油墨并不完全理想。

**做三个小样。** 记下所用黄、蓝颜料的名称，用同一种量具取量，按黄∶蓝约为 1∶1、1∶2、2∶1 分别混匀。在同一张白纸上，每种取相同涂量，涂成大小相近的色块；记录纸张和水量，并在同一光照下比较。湿时看一次，干透后再看一次。可以按“比例／湿时颜色／干后颜色”逐行记下，再决定如何调整。不同材料和比例能说明变化方向，不能预先保证色号。
