微观粒子表现波粒二象性：德布罗意波长 $\lambda = h/p$，频率 $f = E/h$。薛定谔方程 $i\hbar\frac{\partial\psi}{\partial t} = \hat{H}\psi$ 描述波函数演化。波函数模平方 $|\psi|^2$ 为概率密度。算符对应可观测量，本征值为测量可能结果，测量坍缩至本征态。海森堡不确定性：$\Delta x \Delta p \ge \hbar/2$。

**定义：** **量子力学**是描述微观粒子运动规律的理论，用波函数表征系统状态，薛定谔方程决定其时演化，测量概率由波函数模平方给出，不可对易量满足不确定关系。

量子态与概率解释能描述经典轨迹无法说明的原子能级、隧穿和测量结果，是理解半导体、激光及量子器件的基础。势阱模型还可直观看出边界条件如何导致离散能级。

**核心知识/机制**

- **光电效应**：$K_{\text{max}} = hf - W$，光子能量 $E = hf$，确立光量子概念。
- **康普顿散射**：$\Delta\lambda = \frac{h}{m_ec}(1-\cos\theta)$，光子动量 $p = h/\lambda$。
- **德布罗意关系**：$\lambda = h/p$，$f = E/h$（$h=6.626\times10^{-34}$ J·s，$\hbar = h/2\pi$）。
- **薛定谔方程**：
  - 定态：$\hat{H}\psi = E\psi$，$\hat{H} = -\frac{\hbar^2}{2m}\nabla^2 + V(\vec{r})$。
  - 含时：$i\hbar\frac{\partial\psi}{\partial t} = \hat{H}\psi$。

- **波函数统计解释**：$|\psi(\vec{r},t)|^2 dV$ 为在 $dV$ 内找到粒子概率，归一化 $\int|\psi|^2 dV = 1$。
- **算符与本征值**：$\hat{A}\psi_n = a_n\psi_n$，测量结果只能是本征值 $a_n$，概率 $|c_n|^2$（$\psi = \sum c_n\psi_n$）。
- **不确定性原理**：$[\hat{x},\hat{p}] = i\hbar$ 导出同一量子态的位置和动量标准差满足 $\Delta x \Delta p \ge \hbar/2$。能量—时间关系有不同的具体定义，例如寿命与谱线宽度的联系，不能不加说明地把时间当成位置那样的算符。

**例子/可执行步骤：** **例：一维无限深势阱能级**
$V=0$ ($0<x<L$)，$V=\infty$ (其他)。边界条件 $\psi(0)=\psi(L)=0$。
1. 定态方程：$-\frac{\hbar^2}{2m}\frac{d^2\psi}{dx^2} = E\psi$。
2. 解：$\psi_n(x) = \sqrt{2/L}\sin(n\pi x/L)$，$n=1,2,3...$。
3. 能级：$E_n = \frac{n^2\pi^2\hbar^2}{2mL^2} = \frac{n^2 h^2}{8mL^2}$。
4. 零点能 $E_1 > 0$（不确定性原理要求）。
5. 从上式可见 $E_2=4E_1$；阱宽增大到两倍时，在同一能级序号下能量变为原来的四分之一。

**常见误区**

- 【错误】 认为波函数 $\psi$ 是实在的物理波（如声波），实为概率幅，不可直接观测。
- 【错误】 把量子测量的某一种解释当作已由上述概率公式唯一决定；坍缩和退相干的解释需区分模型与实验预测。
- 【错误】 不确定性原理归因于“测量干扰”，实为量子态本身的内在统计性质（制备不确定性）。

**注意**

- 相对论量子力学：克莱因-戈登方程（自旋 0）、狄拉克方程（自旋 1/2，预言反粒子）。
- 量子场论：粒子为场的激发，重整化、标准模型（SU(3)×SU(2)×U(1)）。
- 量子计算：量子比特叠加、纠缠、量子门（酉变换）、Shor 算法、Grover 算法。
