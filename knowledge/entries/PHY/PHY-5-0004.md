原子核由质子、中子（核子）组成，强相互作用束缚。放射性衰变：$\alpha$（He 核）、$\beta^-$（$n\to p+e^-+\bar{\nu}_e$）、$\beta^+$/EC（$p\to n+e^++\nu_e$）、$\gamma$（激发态跃迁）。半衰期 $T_{1/2} = \ln2/\lambda$。裂变：重核分裂释放 ~200 MeV + 中子 → 链式反应。聚变：轻核合成（$D+T\to ^4He+n+17.6$ MeV）需高温高压。辐射防护：时间、距离、屏蔽，ALARA 原则。

**定义：** **核物理**研究原子核结构、衰变、反应及辐射与物质相互作用；**核裂变/聚变**是释放巨大核能的两类反应，**辐射防护**遵循合理尽低（ALARA）原则。

衰变和剂量概念有助于估算放射性随时间的变化，并在医学影像、核能或辐射环境中理解屏蔽与防护原则。区分吸收剂量和当量剂量，对解释不同辐射的生物影响尤其重要。

**核心知识/机制**

- **核素表示**：$^A_ZX$（$Z$ 质子数，$N$ 中子数，$A=Z+N$ 质量数）。同位素（同 $Z$）、同量异位素（同 $A$）、同中子素（同 $N$）。
- **结合能**：`$B =\[Z m_p + N m_n - m_(#text(font: "Noto Sans SC", weight: 400)[核])\]c^2$`{=typst}，这里 `$m_(#text(font: "Noto Sans SC", weight: 400)[核])$`{=typst} 指原子核质量；若使用中性原子质量，应另行处理电子质量。中等质量核的平均结合能约为每核子 8—9 MeV，铁、镍附近较高。
- **衰变定律**：$N(t) = N_0 e^{-\lambda t}$，活度 $A = \lambda N$（单位贝克勒尔 Bq），$T_{1/2} = \ln2/\lambda$。
- **主要衰变模式**：
  - $\alpha$：$^A_ZX \to ^{A-4}_{Z-2}Y + ^4_2\alpha$（$Q>0$ 仅重核）
  - $\beta^-$：$n \to p + e^- + \bar{\nu}_e$，$Z\to Z+1$，$A$ 不变
  - $\beta^+$/EC：$p \to n + e^+ + \nu_e$ / $p + e^- \to n + \nu_e$，$Z\to Z-1$
  - $\gamma$：激发核 $\to$ 基态核 + $\gamma$ 光子（能量 keV-MeV）

- **裂变**：$^{235}$U + $n \to$ 两中等质量核 + 2~3 $n$ + ~200 MeV。临界质量、增殖因子 $k$。
- **聚变**：$D + T \to ^4He (3.5\text{ MeV}) + n (14.1\text{ MeV})$，劳森准则 $n\tau_E T > 3\times10^{21}$ keV·s/m³。
- **辐射量**：
  - 吸收剂量 $D$ (Gy = J/kg)
  - 当量剂量 $H = w_R D$ (Sv)，$w_R$：$\gamma/\beta=1$，$n=5\sim20$，$\alpha=20$
  - 有效剂量 $E = \sum w_T H_T$ (Sv)，组织加权因子 $w_T$

- **防护原则**：尽量缩短接触时间、增加距离并使用适当屏蔽；反平方规律适用于理想点源等特定几何条件。窄束未散射光子的指数衰减并不自动等于实际总剂量的衰减。

**例子/可执行步骤：** **例：用半衰期计算活度变化**
若某单一核素的初始活度为 800 Bq，经过一个半衰期后约为 400 Bq，经过两个半衰期后约为 200 Bq。这里假设没有其他来源加入，也未把衰变产物的活度计入。活度表示单位时间的核衰变次数，不能直接换算成某人受到的剂量。

**常见误区**

- 【错误】 认为“半衰期过完就没辐射了”，实每过一半衰期活度减半，理论永不为零。
- 【错误】 只按穿透距离判断危险。外照射时纸张可阻挡不少 α 粒子，但含 α 放射性物质吸入或吞入体内仍可造成严重伤害；具体穿透能力随辐射能量及介质而变。
- 【错误】 核聚变“无辐射”，实 D-T 反应 80% 能量带 14 MeV 中子，激活结构材料产生活性废物。

**注意**

- 厚屏蔽层中的散射光子也可能到达测点，屏蔽设计需结合核素、能量、几何和散射，由专业人员计算并实测。核废物分类与处置还须遵循适用规定。
- 核安全深度防御：燃料包壳→压力容器→安全壳→应急规划区。
- 核扩散风险：浓缩铀/钚分离技术受 IAEA 保障监督（NPT 条约）。
