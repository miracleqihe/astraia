自动化测试系统：仪器（GPIB/USB/LAN/RS-232）→ 总线控制器 → 软件。SCPI 指令集标准化仪器通信（`*IDN?`、`MEAS:VOLT?`、`SOUR:VOLT 5`）。数据采集卡 (DAQ)：模拟输入 (AI)、模拟输出 (AO)、数字 I/O、计数器/定时器。关键参数：采样率、分辨率、通道数、触发模式。LabVIEW 图形化数据流；Python + PyVISA/InstrumentKit + NumPy/SciPy 现代替代。测试流程：初始化→配置→采集→分析→报告→清理，异常处理与资源释放必做。

**定义：** **自动化测量**用软件控制仪器与数据采集硬件完成既定测试序列，提升重复性、吞吐率与可追溯性；**SCPI/VISA/DAQmx**是互操作的标准化接口层。

自动采集能让重复测量一致、快速，并留下仪器设置与样品数据以便复核。设计好触发、异常处理和资源清理，可减少漏测、误读及长时间测试中的设备占用问题。

**核心知识/机制**

- **仪器总线**：
  - GPIB (IEEE-488)：并行总线；常规配置包括控制器在内最多 15 个物理设备，总线电缆总长通常不超过 20 m，还应满足相邻间距等限制。
  - USBTMC：USB 封装 GPIB 协议，即插即用。
  - LXI (LAN)：

以太网，远程可达，支持 IPv6/VXI-11/HiSLIP。
  - RS-232/485：串行，长距离，波特率设置需匹配。

- **VISA 层**：统一资源字符串 `TCPIP0::192.168.1.100::inst0::INSTR`，`viOpen`/`viWrite`/`viRead`/`viClose`。
- **SCPI 命令树**：子系统 `SOURce`、`MEASure`、`SENSe`、`OUTPut`、`SYSTem`、`STATus`。查询命令加 `?`。
- **DAQ 关键概念**：
  - 任务：通道组 + 时序 + 触发 + 缓冲区。
  - 触发：模拟边沿、数字电平、软件、时间。
  - 采样模式：有限点数、连续、硬件定时。

- **Python 生态**：
  - `pyvisa` + `pyvisa-py`（纯 Python 后端）或 NI-VISA 后端。
  - `nidaqmx` (NI 官方)，`mcculw` (Measurement Computing)，`dwf` (Digilent)。
  - 数据处理：`numpy`、`scipy.signal`、`pandas`、`matplotlib`/`plotly`。

- **测试软件工程**：
  - 驱动层（类封装仪器）、序列层（步骤/参数/判据）、报告层（HTML/PDF/数据库）。
  - 版本控制（Git）、CI/CD（GitHub Actions）、容器化（Docker 含 NI 驱动镜像）。

**例子/可执行步骤：** **例：连接仪器并准备测量滤波器频响**

先用资源字符串连接仪器，读取身份并确认型号。下面只演示连接与释放资源，地址需按现场设备填写：

```python
import pyvisa

rm = pyvisa.ResourceManager()
try:
    inst = rm.open_resource("TCPIP0::192.168.1.50::inst0::INSTR")
    try:
        inst.timeout = 10000  # 通信超时，单位为毫秒
        print(inst.query("*IDN?").strip())  # 读取仪器身份
    finally:
        inst.close()
finally:
    rm.close()
```

真正测 S21 时，先按该型号手册选择测量参数和通道，完成适用的校准，设置扫频方式、频率范围和点数；启动测量并确认完成后，读取实际频率轴和复数或格式化结果，再核对数据长度与单位。不同厂家的命令、默认轨迹及数据格式可能不同；简单读取当前显示轨迹，不能保证读到 S21，也不能在未确认线性扫频时用等间隔数组代替实际频率轴。

**常见误区**

- 【错误】 不核查仪器的前次配置就开始采集。`*RST` 和 `*CLS` 会改变状态或清除信息，执行前应确认仪器手册及现场条件，不应把复位当成对任何设备都安全的默认步骤。
- 【错误】 读取大数据用 ASCII (`FORM:DATA ASC`) 慢，应用二进制 (`FORM:DATA REAL,32`/`INT,16`) + 块传输。
- 【错误】 程序异常退出未 `close()` 资源，导致总线锁定、仪器挂起，需 `try/finally` 或上下文管理器。

**注意**

- 实时/确定性要求高（µs 级闭环）需 FPGA/实时控制器，PC 软件定时抖动 ~ms 级不可靠。
- 多仪器同步触发：共享触发总线（GPIB GET、LXI IEEE-1588 PTP、PXI 后板触发线）。
- 测试数据完整性：元数据（时间戳、软件版本、仪器固件版、校准日期、环境温湿度）随原始数据存储。
