定轴转动类比质点平动：角位移 $\theta$、角速度 $\omega$、角加速度 $\alpha$；力矩 $\tau = I\alpha$，转动惯量 $I = \sum m_i r_i^2$；转动动能 $K_{\text{rot}} = \frac{1}{2}I\omega^2$。平行轴定理：$I = I_{\text{cm}} + Md^2$。

**用扳手时看哪段距离。** 同样的垂直作用力，离螺栓转轴越远，产生的力矩越大：在 0.2 m 的力臂上施加 50 N，力矩大小为 10 N·m。力若与扳手近乎平行，有效力臂会缩短；真正的力臂是转轴到力作用线的垂直距离。

转动惯量也要先指定转轴。手持长杆绕一端转动与绕中点转动，即便杆的质量相同，对同一角加速度所需力矩也不同。

**刚体定轴转动**：刚体绕固定轴旋转，各质点做同心圆周运动，共享相同 $\omega, \alpha$；**转动惯量**表征质量分布对转动惯性的大小，取决于转轴位置。

转动惯量和力矩能解释为什么长柄工具更省力、飞轮更难改变转速，也可用于计算滑轮和滚动物体的加速度。识别转轴位置尤其重要，因为同一物体绕不同轴转动时惯量不同。

**原理与计算**

- **运动学**：$\omega = d\theta/dt$，$\alpha = d\omega/dt$，$v = r\omega$，$a_t = r\alpha$，$a_n = r\omega^2$。
- **力矩**：$\vec{\tau} = \vec{r} \times \vec{F}$，大小 $\tau = rF\sin\phi = F d$（力臂 $d$），单位 N·m。
- **牛顿第二定律旋转形式**：$\tau_{\text{net}} = I\alpha$（标量，定轴）。
- **转动惯量常见几何体**：
  - 细棒端点：$I = \frac{1}{3}ML^2$；中心：$I = \frac{1}{12}ML^2$
  - 圆环/薄圆柱壁：$I = MR^2$
  - 实心圆柱/圆盘：$I = \frac{1}{2}MR^2$
  - 实心球：$I = \frac{2}{5}MR^2$；薄球壳：$I = \frac{2}{3}MR^2$

- **平行轴定理**：$I = I_{\text{cm}} + Md^2$（$d$ 为新轴与过质心平行轴距离）。
- **转动动能**：$K = \frac{1}{2}I\omega^2$；滚动不滑动：$v_{\text{cm}} = R\omega$，`$K_(#text(font: "Noto Sans SC", weight: 400)[总]) = 1 / 2 M v_(upright("cm"))^2 + 1 / 2 I_(upright("cm")) omega^2$`{=typst}。

**计算示例：** **例：滑轮系带有转动惯量的滑轮**
1. 设滑轮半径 $R$，转动惯量 $I$，两侧张力 $T_1, T_2$。
2. 滑轮转动方程：$(T_1 - T_2)R = I\alpha$。
3. 绳不滑：$\alpha = a/R$ → $(T_1 - T_2) = I a / R^2$。
4. 结合挂质点 $m_1, m_2$ 的平动方程联立求 $a$。

**容易混淆的地方**

- 【错误】 力矩与力、力臂混淆：力矩取决于**力臂**（垂直距离），非位置矢量模长。
- 【错误】 转动惯量当作与转轴无关；转轴改变时须重新计算，平行轴之间可使用平行轴定理。
- 【错误】 认为静摩擦在任何情况下都不做功。物体在固定水平地面纯滚动时，接触点相对地面瞬时静止，静摩擦对该物体瞬时功率为零；接触面运动时则可能做功。

**适用条件**

- 非定轴转动（如陀螺、自由刚体）一般需使用惯量张量 $\mathbf{I}$ 和角动量关系 $\vec{L} = \mathbf{I}\cdot\vec{\omega}$，并结合欧拉方程；不能普遍用标量惯量相乘。
- 变转动惯量系统（如收臂花样滑冰）角动量守恒 $I\omega = \text{const}$，动能不守恒（内力做功）。
- 单位核对：$\tau$ [N·m]，$I$ [kg·m²]，$\omega$ [rad/s]，$K$ [J]。
