电势 $V = U/q$ 是标量势，$\vec{E} = -\nabla V$。点电荷 $V = kq/r$（无穷远零点）。等势面 $\perp$ 电场线。电容器：两导体带等量异号电荷，电容 $C = Q/V$。平板电容器 $C = \varepsilon A/d$。储能 $U = \frac{1}{2}CV^2 = \frac{1}{2}QV = \frac{1}{2}Q^2/C$。

**定义：** **电势**是单位电荷的电势能，标量场，梯度给出电场；**电容器**是储存电荷和电能的器件，电容表征储存电荷能力，仅取决于几何结构和介质。

电势是标量，常比逐项处理电场矢量更方便，用于计算电荷移动的能量变化和电路中的电压。电容与储能关系还解释了闪光灯、滤波电路及断电后平板间距变化时的能量变化。

**核心知识/机制**

- **电势差**：$V_B - V_A = -\int_A^B \vec{E} \cdot d\vec{l}$，路径无关（静电场保守）。
- **点电荷电势**：$V = \frac{1}{4\pi\varepsilon_0}\frac{q}{r}$（无穷远 $V=0$）。
- **连续分布电势**：$V = \int \frac{k dq}{r}$，标量积分比矢量积分简便。
- **等势面**：$V=$ 恒定的曲面，$\vec{E} \perp$ 等势面，导体表面是等势面。
- **电容定义**：$C = Q/V$（$Q$ 为一极板电荷量），单位法拉（F）。
- **常见电容器**：
  - 平板：$C = \varepsilon A/d$（$A$ 面积，$d$ 间距，$d \ll \sqrt{A}$）
  - 球形：$C = 4\pi\varepsilon \frac{R_1 R_2}{R_2 - R_1}$（同心球壳）
  - 圆柱：$C = \frac{2\pi\varepsilon L}{\ln(R_2/R_1)}$（同轴圆柱）

- **介质影响**：填介电常数 $\varepsilon_r$ 介质，$C$ 增大 $\varepsilon_r$ 倍。
- **串联/并联**：串联 $1/C_{\text{eq}} = \sum 1/C_i$，对初始中性且中间节点孤立的理想电容器，极板电荷量相同；并联 $C_{\text{eq}} = \sum C_i$，两端电压相同。
- **电容器储能**：$U = \frac{1}{2}CV^2$，能量密度 $u = \frac{1}{2}\varepsilon E^2$（场内分布）。

**例子/可执行步骤：** **例：理想带电平板电容器断电后拉大极板间距**
假设极板绝缘良好、没有电荷泄漏且忽略边缘效应；实际元件和电路还会受漏电等影响。
初态：$C_0 = \varepsilon A/d_0$，电荷 $Q_0$，电压 $V_0$，能量 $U_0 = Q_0^2/(2C_0)$。
1. 断电 → $Q$ 守恒（$Q = Q_0$）。
2. 拉至 $d = 2d_0$ → $C = C_0/2$。
3. 新电压 $V = Q/C = 2V_0$。
4. 新能量 $U = Q^2/(2C) = 2U_0$（能量增加，外力做功 $W = U - U_0 = U_0$）。

**储能算例。** 理想 100 μF 电容器两端为 12 V 时，$U=\frac12 CV^2=0.0072$ J，即 7.2 mJ。此公式说明电压升高时储能按电压平方增加；实际设备断电后也可能留有电压。

**常见误区**

- 【错误】 认为电容 $C$ 与电荷 $Q$、电压 $V$ 有关，实 $C$ 仅由几何和介质决定。
- 【错误】 串联电容器分压比电容比，实 $V_1/V_2 = C_2/C_1$（$Q$ 同，$V \propto 1/C$）。
- 【错误】 能量公式 $U = \frac{1}{2}QV$ 中 $Q,V$ 为同一状态下的值，不可混用初末态量。

**注意**

- 介质击穿场强 $E_{\text{max}}$ 限制最大工作电压 $V_{\text{max}} = E_{\text{max}} d$。
- 有极性的电解电容应按极性和额定值使用，反接可能导致损坏或破裂；陶瓷电容通常无极性，某些介质可能产生压电微音效应。
- 高频下电容呈现寄生电感（ESL）和等效串联电阻（ESR），在简化串联模型下阻抗大小 $|Z| = \sqrt{ESR^2 + (\omega L - 1/\omega C)^2}$。
