可逆反应达到动态平衡时，正逆过程仍在进行，但速率相等，体系组成不再发生净变化。反应商 $Q$ 与平衡常数 $K$ 的比较可以帮助判断反应的净进行方向；改变温度、组成或体积可能使体系重新趋向平衡。催化剂改变达到平衡的速度，不改变给定温度下的平衡常数；定温定容下给理想气体体系加入惰性气体，也不等于使用了催化剂。

**定义：** **化学平衡**是可逆反应正逆速率相等的动态稳态，**平衡常数**量化平衡组成，**勒夏特列原理**预测外界条件变化对平衡位置的影响方向。

平衡常数与反应商能定量判断可逆反应的组成和移动方向，适用于合成条件选择、溶液配制和气体平衡计算。辨清升温、压强或加入惰性气体的影响，可避免把“平衡移动”误当成改变平衡常数。

**核心知识/机制**

- **平衡常数表达式**：标准热力学平衡常数使用相对于标准态的无量纲活度；纯固体或纯液体相存在时，其活度按约定取 1。特定反应与标准态下的标准平衡常数是温度的函数。
- **$K_p$ 与 $K_c$ 换算**：理想气体计算中，若约定使用分压和浓度的相应量纲式，可写作 $K_p = K_c(RT)^{\Delta n_g}$，$\Delta n_g$ 为气体生成物与反应物化学计量数之差；使用无量纲标准态常数时还须明确所采用的标准压力、浓度和单位，不能直接混用不同定义。
- **判断平衡方向**：计算 $Q$ 与 $K$ 比较。
- **勒夏特列应用**：
  - 在其他条件固定时，提高参与平衡表达式的反应物活度，或降低生成物活度，通常使体系向正向调整；增加已经存在的纯固相数量通常不改变其活度，不能一概套用。
  - 在理想气体、定温条件下压缩体积，会改变各反应气体分压；若反应前后气体化学计量数不同，平衡倾向于气体物质的量较少的一侧。不同的增压方式不可一刀切。
  - 升温时，若正反应吸热，平衡倾向正向、$K$ 随温度增大；若正反应放热，平衡倾向逆向、$K$ 随温度减小。具体还应结合反应焓和温度范围。
  - 催化剂可以使体系更快达到平衡，但不改变平衡常数或平衡组成；定温定容加入不参与反应的理想惰性气体时，各反应气体分压不变，平衡不因总压增加而移动，这不是催化作用。[src-che-012a][src-che-012b]

- **平衡计算**：ICE 表（Initial, Change, Equilibrium）列式解方程。

**例子/可执行步骤：** **例：$N_2 + 3H_2 \rightleftharpoons 2NH_3$，$\Delta H < 0$。某温度下采用以 atm 分压直接写出的量纲式，$K_p = 4.0\times10^{-4}\,\mathrm{atm}^{-2}$。初始 $p_{N_2}=1$ atm，$p_{H_2}=3$ atm，$p_{NH_3}=0$。求平衡分压。**
1. ICE：$N_2: 1-x$，$H_2: 3-3x$，$NH_3: 2x$。总压 $P=4-2x$。
2. 定温定容时各组分分压按反应进度改变，故 $p_{N_2}=1-x$、$p_{H_2}=3-3x$、$p_{NH_3}=2x$（atm），总压 $P=4-2x$。
3. 把各分压按 atm 为单位代入 $K_p=\frac{p_{NH_3}^2}{p_{N_2}p_{H_2}^3}$；对应数值满足 $\frac{(2x)^2}{(1-x)(3-3x)^3}=4.0\times10^{-4}$，解得 $x\approx0.04717$ atm。这里方程中的 $x$ 取以 atm 为单位的数值。
4. 平衡分压：$p_{N_2}\approx0.9528$ atm，$p_{H_2}\approx2.8585$ atm，$p_{NH_3}\approx0.09435$ atm。

**常见误区**

- 【错误】 认为“加惰性气体总不会移动平衡”：在定温、定压的理想气体体系中，加入惰性气体使体积增大；若反应前后气体化学计量数不同，平衡倾向气体物质的量较多的一侧，若相同则不因这一变化而移动。
- 【错误】 不区分标准平衡常数与教材中的浓度式：前者以无量纲活度定义；后者是否带量纲取决于写法、标准态与约定。
- 【错误】 “$K$ 超过固定数值就一定完全反应”：平衡组成还取决于反应式、初始组成与条件，不能对所有反应使用同一个完成度阈值。

**注意**

- 离子反应平衡：溶度积 $K_{sp}$、酸碱 $K_a/K_b$、配位 $K_f$、氧化还原 $E^\circ$（能斯特方程）。
- 多重平衡耦合：同离子效应、缓冲溶液、络合沉淀分离。
- 非理想体系需要用相对于标准态的活度；采用浓度标准态时可写 $a_i=\gamma_i c_i/c^\circ$，活度系数的定义和近似方法依体系而异。
