原子由核（质子+中子）与核外电子组成。电子占据量子态，由四量子数（$n,l,m_l,m_s$）标记。排布遵循：基态优先占据较低能量状态（$n+l$ 规则只作近似，有例外）、泡利不相容（轨道最多 2 电子自旋相反）、洪特规则（同亚层先单占自旋平行）。周期表按原子序数排列，同族元素价电子排布相似 → 化学性质相似；周期性趋势：半径（左→右减、上→下增）、电离能/电负性（左→右增、上→下减）。

**定义：** **原子结构**描述电子在核外运动的量子态分布；**周期律**是元素性质随原子序数周期性变化的规律，本质源于电子层结构的周期性填充。

电子排布能帮助解释同族元素为何性质相似，并预测原子失电子、得电子和成键倾向。掌握周期趋势后，可在未知元素题目或材料选择中快速形成可检验的判断。

**核心知识/机制**

- **原子组成**：质子数 $Z$ = 原子序数 = 电子数（中性原子）；中子数 $N$；质量数 $A = Z+N$。同位素：同 $Z$ 不同 $N$。
- **量子数与轨道**：
  - $n=1,2,3...$（主层，K/L/M...）
  - $l=0,1,...,n-1$（s/p/d/f...，亚层）
  - $m_l=-l...+l$（轨道取向，$2l+1$ 个）
  - $m_s=\pm 1/2$（自旋）

- **排布顺序（$n+l$ 规则）**：1s < 2s < 2p < 3s < 3p < 4s < 3d < 4p < 5s < 4d < 5p < 6s < 4f < 5d < 6p < 7s < 5f < 6d...
- **例外排布**：Cr ($[Ar]4s^1 3d^5$)、Cu ($[Ar]4s^1 3d^{10}$) 等半满/全满亚层更稳定。
- **周期性趋势**：
  - 原子半径：同周期核电荷增大 → 半径减；同族电子层数增 → 半径增。
  - 电离能：首电离能同周期增、同族减（惰性气体最高）。
  - 电负性（Pauling 标度）：F 最高 3.98，Cs/Fr 最低 ~0.7。
  - 电子亲和能：卤素最大（易得电子成稳定阴离子）。

**例子/可执行步骤：** **例：写出 Se (Z=34) 的电子排布及价电子数**
1. 按 $n+l$ 规则填充：1s² 2s² 2p⁶ 3s² 3p⁶ 4s² 3d¹⁰ 4p⁴。
2. 简写：[Ar] 4s² 3d¹⁰ 4p⁴ 或 [Ar] 3d¹⁰ 4s² 4p⁴。
3. 价电子：最外层 $n=4$ 的 4s² 4p⁴ 共 6 个（VI A 族）。

**常见误区**

- 【错误】 把中性原子的填充顺序直接当作所有离子的失电子顺序；许多第一过渡系元素形成阳离子时先失去 4s 电子，轨道能量会随电子数和状态变化。
- 【错误】 将“族号”直接等同于价电子数，过渡金属族号与价电子关系复杂（如 Fe 族 8 族但价电子常 2/3）。
- 【错误】 忽略镧系收缩导致 5d 元素半径与 4d 相近（如 Zr/Hf、Nb/Ta 性质极似）。

**注意**

- 超重元素（$Z>118$）相对论效应显著：$s/p$ 轨道收缩稳定，$d/f$ 轨道扩展不稳定，化学性质偏离周期律外推。
- 离子半径：阳离子 < 中性原子 < 阴离子（同核电荷下电子数减/增）。
- 电负性差 $\Delta\chi$ 判断键型：$\Delta\chi < 0.4$ 非极性共价，$0.4\sim1.7$ 极性共价，$>1.7$ 离子键为主（仅经验界限）。
