**用途与判断：** 双栈主机可能同时有 IPv4 与 IPv6 地址，但应用优先选择 IPv6 后因路由、RA 或防火墙配置不完整而卡顿。应分别验证地址、默认路由和目标服务，不因 IPv4 正常就认定 IPv6 正常。

**现场实操**：同一网址在公司 Wi-Fi 上等待数秒后打开：分别用 `ping -6`、`tracert -6` 和 IPv4 对照，检查 IPv6 默认路由及边界防火墙；若只在某网段失败，移交网络管理员检查 RA、前缀路由和 ACL，而非全网关闭 IPv6。

分别观察域名返回的 A 与 AAAA 地址，并对获授权的目标比较 IPv4 和 IPv6 的业务连接。`ping -6` 未回应可能只是 ICMP 被过滤，不能单凭它断定 TCP 服务不可用；双栈客户端也可能并行或错开尝试两种地址，表现取决于实现。

**安全步骤：** 记录地址前缀、网关、接口和时间；使用授权测试目标；变更前导出路由/防火墙配置并准备回滚；复测 DNS 返回的 A/AAAA 路径和业务端口。

**误区与边界：** IPv6 地址不经 NAT 不等于暴露必然增加，但防火墙策略需明确配置；不要未经授权扫描公网地址。
