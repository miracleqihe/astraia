花、果、茎和叶可为植物分类提供线索，但一种外形常出现在多个科内，同科不同种的毒性也可能不同。要记录完整植株、地点和季节，并用地区植物志或专业人员核对。

| 植物类群 | 常见观察点 | 生活中应留意 |
|---|---|---|
| 十字花科 | 四瓣十字形花常见，花和果的组合有助识别 | 白菜、萝卜及芥菜等属于该科；不要用单朵花断定野生物种可食。 |
| 茄科 | 部分种有五裂花冠、显眼花药或浆果 | 栽培番茄、马铃薯与有毒曼陀罗同科；野生果实不因与食材相似就安全。 |
| 芸香科 | 柑橘类叶常有油点或芳香 | 西柚可能与部分药物发生相互作用，具体应问医生或药师。 |
| 葫芦科 | 一些种类蔓生并具卷须 | 食用瓜类若明显异常发苦应停止食用并丢弃，不靠试舔筛选野果。 |
| 伞形科 | 许多种类有伞状花序 | 食用水芹与毒芹等可能混淆；不采食未确认的野生植株。 |
| 豆科 | 很多种类有荚果 | 鸡母珠有毒；食用干豆按可靠方法充分浸泡并煮熟。 |
| 蔷薇科 | 很多种类有五瓣花及多枚雄蕊 | 杏、桃等果核仁与果肉不同；不嚼碎或大量食用不明核仁。 |
| 葱属 | 叶及鳞茎因种类而异 | 水仙与葱蒜可能混放或误认；单凭气味不能保证准确鉴别。 |
