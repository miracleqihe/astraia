## 一、核心思想与哲学架构

Astraia 不把神话、鬼故事和数字都市传说简单“证伪成错觉”，也不把物理与历史考据神秘化为“超自然证据”，而是建立了一套**心物平行、可观而不可涉**的双界认识论框架：

### 1. 「朔望叠影」与心物并读（PHYSIS × MYTHOS）
天文上，日、地、月一线相合称**朔（Syzygy / 隐）**，相对满照称**望（显）**。本图谱以**上卷 · 玄象志怪（MYTHOS）**承载地方志乘、神话母题、梦魇亲历与现代数字民俗，以**下卷 · 格物识微（PHYSIS）**承载声学、毒理、认知神经科学、史学、社会学与哲学条目。两者并行并读、相互映照，但**始终保留原图谱中独立的证据边界**：算法和关键词配对只标记对读线索，绝不自动制造新的“已证实”关系。

### 2. 波动界膜与「第四面墙」（可观而不可涉）
在「朔望叠影」三维视图中，屏幕并非冷冰冰的平面容器，而是一层随光标压迫和跨界动作产生实时光影折射（`WebGL` 渲染通道 `membraneRefraction.js` + 表面微澜 `membrane.js`）与可选程序化声景（`membraneAudio.js`）的**波动界膜**：
- **可触可涉（人界 / 界膜临界）**：位于物界一侧或悬停于默认 `0.5` **界膜临界点**时，既能直触物质星点与筛选控件，也能向内窥见精神世界投影。
- **可观不可涉（鬼 / 聻 / 希 / 夷）**：一旦穿越界膜进入更深维度，精神维度可以隔膜观察物质世界的运转，却**无法对物界发号施令或篡改筛选**——此时点击物界控件只会触发一阵带古典低语的金色膜面波纹与提示：「身处界膜彼岸：此界可观不可涉，点击『人』或『界膜』即可返界操作」。

### 3. 五重界阶谱系：「人死为鬼，鬼死为聻，聻死为希，希死为夷」
底部「五重界阶仪」沿中国古籍《子不语·为聻》与老子“听之不闻名曰希，视之不见名曰夷”的层次递进，将观察深度划分为六个刻度：

| 刻度 | 界阶名称 | 哲学释义与界面联动 | 物界操作权限 |
| --- | --- | --- | --- |
| `0.0` | **Ⅰ 人 · 实存物界** | 立身实测之境，直触地理坐标、物理规律与典籍原页，隔膜仍可遥观彼岸微光。 | 可观可涉 |
| `0.5` | **◐ 界膜 · 朔望临界** *(默认)* | 朔隐望显、一线相叠的波动薄翳。可回手定物，亦可移动光标压弯膜面窥见彼岸。 | 可观可涉 |
| `1.0` | **Ⅱ 鬼 · 人死为鬼** | 紧贴物界背面的执念、夜谈与亲历经验：“他人不见，惟亲历者见之。” | 可观不可涉 |
| `2.0` | **Ⅲ 聻 · 鬼死为聻** | 个体姓名与街巷坐标剥落，自动跃迁并聚焦 `SIDERA · 玄象星络`，只余跨文化原型共振。 | 可观不可涉 |
| `3.0` | **Ⅳ 希 · 聻死为希** | 听之不闻的隐性律动，切入 `OMNIA · 万象星枢` 背后不以人心惊怖而改的机理框架。 | 可观不可涉 |
| `4.0` | **Ⅴ 夷 · 希死为夷** | 视之不见的高维悬置视点——展开右上**「第四面墙 · 夷阶观测者视窗」**，将画框外的**实时本地时刻、实时天文月龄月相、你的浏览器物理视口尺寸、触膜微澜次数**与个人**格物/玄象阅读倾向天平**直接显影于界面之上，并附**《子不语·为聻》⇄《道家名言边界》**典籍直达示范。 | 可观不可涉（膜外凝视） |

### 4. 八维折光哲思棱镜（Logos）与三项感官边界微实验
每当开启一对心物星桥（或通过「穿界星门」自选配对），手卷中段的 **LOGOS · 折光哲思** 会按条目语境映射 8 组哲学追问并关联《格物识微》哲学锚点（[philosophicalPrism.js](web/src/syzygy/philosophicalPrism.js)）：
- **八大哲思母题**：① 感官即边界、② 命名即秩序、③ 他者与恐慌、④ 场所与记忆沉积、⑤ 虚构反噬现实（展演 Ostension）、⑥ 模型与深渊（知识边界）、⑦ 技术盲区与媒介幽灵、⑧ 生死刻度：人、鬼、聻、希、夷。
- **三项交互式感官微实验**（随话题自动嵌入阅读卷宗内）：
  1. **视网膜余像（无中生影）**：10 秒中心铜十字凝视，直观见证空白画布自发显影的反色暗影。
  2. **声学听阈与 19 Hz 临界波形**：实时 Canvas 示波器 + Web Audio 合成，对比 `19 Hz 临界`（接近人耳下限、感压而不闻）、`44 Hz 低频` 与 `110 Hz 基准`。
  3. **空想性错视与噪点阈值**：可调对比度随机灰度噪点画布（`0.6×–3.4×`），体验大脑如何在无序噪声与留白之间“认出”面孔与轮廓。

### 5. 学术边界与信源纪律
- **五级信源印章（S / A / B / C / F）**：`S` 学术研究与机理、`A` 一手历史/地方/司法档案、`B` 民间口述与田野传说、`C` 二次文献与地方汇辑、`F` 现代数字创作与文学虚构（默认开启「隔离 F 级」以保持实证视图纯粹，用户可一键放行）。
- **四层对读与原图谱证据独立**：星桥区分**精选对读（`curated`）**、**母题/结构传导（`relay`）**、**主题关联（`theme`）**与**阅读指引（`guide`）**；若原图谱存在 `EXPLAINED_BY` 关系，单独标示 `✓ 已证实（confirmed）`、`? 有争议（contested）`、`? 待核实（unverified）`、`✕ 已驳回（refuted）`，从不将机制假说偷换为定论。
- **地理诚实原则**：无可靠地点的材料（如部分古籍笔记、母题索引或数字原生虚构）只进入星络与目录，绝不伪造地球经纬度；城市/区域级参考坐标明确加注参考点依据。

## 五、轻量化双层部署架构（GitHub Pages + Cloudflare R2）

为使万人节点、两千余篇格物条目、原版 PDF 及多语插图在浏览器极速开启，同时规避单仓库静态托管膨胀，发布流采取以下分层优化：

1. **轻量页面层（GitHub Pages `miracleqihe.github.io/astraia/`）**：托管精简 HTML/JS/CSS 入口、经典精查快照索引与朔望首屏摘要（`syzygy/boot.json` 含 287 座星桥预览与匹配统计，总首屏包体紧致快速），同时保留历史带哈希脚本避免强缓存页面断链；并为每条新增/既有 L1 记录生成静态分享页。
2. **大体积资源层（Cloudflare R2 对象存储）**：大体积全文包、原书高清 PDF、文内插图、原典扫描页图（WebP）以及 **128 个经 SHA-256 校验的按需阅读分片桶（`syzygy/shards/`）** 均由网站发布流水线同步并核验至 R2；前端通过 [publicAssetUrl.js](web/src/publicAssetUrl.js) 根据页面内嵌 `astraia-r2-assets` 资产清单按需拉取，并妥善处理中文路径百分比编码与 `Range` 分段读取 PDF。
3. **双渲染通道与零缺字字体包**：前端探测到可靠硬件加速时使用 `WebGL2`，检测到软件光栅化（SwiftShader/llvmpipe/WARP）或无 GPU 环境时自动切换为轻量 Canvas 2D 星点光晕投射（[renderer.js](web/src/syzygy/renderer.js)），并遵循系统 `prefers-reduced-motion`；所有中文由随站打包的 `Noto Serif SC`（400/600）、`Noto Sans SC`、`Noto Sans Thai/Lao/Khmer/Buginese`、`SIL Charis` 与自研扩展字形子集承载，确保 **6,356+ 汉字零缺失**。
