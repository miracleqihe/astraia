## 故事梗概

西苏门答腊的沙瓦伦托曾依靠煤矿与铁路发展。矿业衰退后，旧矿道和工人故事被重新讲述，一些居民把黑暗隧道与矿工亡魂的传闻联系在一起。

2014 年的报道把这种夜谈放进城市寻求转型的背景中。有关矿工人数和具体死亡经过的传闻需要独立史料核实，不能直接当作矿难统计。

联合国教科文组织的矿业遗产资料介绍了矿井、铁路和港口之间的联系。把遗产记录与城市传闻并读，能看到劳动史与后来的地方想象如何交错。

## 地图与年代

沙瓦伦托市为矿业遗产和传闻的城市参考；地下矿道并未逐条定位。
